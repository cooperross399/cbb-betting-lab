# Ratings tables dropped by hand

Cooper's way to give the card a published ratings table this lab does not
fetch itself (decision 92): T-Rank, whose robots.txt closes barttorvik.com to
this lab's agent by name, or any other table a subscription lets him export.

Name the file `<source>_<YYYY-MM-DD>.csv`, lower-case source, the date being
the day the table was downloaded: `trank_2026-11-10.csv`. The file must have a
header row naming the team and adjusted offence and defence (`Team`, `AdjOE`,
`AdjDE`, optionally `AdjT`), as T-Rank's own CSV export does.

The newest file per source dated on or before the slate day is read, and like
every published table it stops counting two days after its date, so a drop
helps only while it is fresh. It joins the consensus beside ESPN's power
index, KenPom and the NET; nothing else about the card changes.
